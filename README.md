# Stellar Trading Bot

## Описание
Этот бот автоматически торгует парой RUV/XLM на блокчейне Stellar с использованием технического анализа и управления рисками.

## Стратегия торговли
### Индикаторы:
- **MA (Moving Average)**: Среднее значение цены за последние 14 периодов.
- **RSI (Relative Strength Index)**: Измеряет скорость и изменение ценовых движений (период 14).
- **MACD (Moving Average Convergence Divergence)**: Сравнивает две скользящие средние (12 и 26 периодов).

### Условия для покупки:
- Цена выше MA
- RSI < 30 (перепроданность)
- MACD пересекает сигнальную линию снизу вверх

### Условия для продажи:
- Цена ниже MA
- RSI > 70 (перекупленность)
- MACD пересекает сигнальную линию сверху вниз

### Управление рисками:Основные функциональные возможности проекта:
Полная реализация торговой логики :
Генерация сигналов на основе технических индикаторов
Исполнение сделок через Stellar SDK
Закрытие позиций при достижении стоп-лосса или тейк-профита
Трейлинг-стоп для управления рисками
Система управления рисками :
Расчет позиции на основе ATR и фиксированного процента риска
Динамическая корректировка риска в зависимости от просадки
История сделок и аналитика прибыльности

Агрегация данных :
Преобразование сырых сделок в свечи заданного интервала
Поддержка различных временных интервалов (1m, 5m, 15m, 1h, 1d)
Система мониторинга и защиты :
Проверка здоровья системы
Автоматический перезапуск при сбое
Уведомления о критических событиях
Защита от дублирования сделок
Хранилище данных :
SQLite для хранения позиций, ордеров и истории сделок
Полная аудит-логика всех операций

Масштабируемость :
Простая интеграция новых стратегий
Возможность добавления новых источников данных
Гибкая система управления рисками


- **Стоп-лосс**: Установлен на 2% от цены входа
- **Тейк-профит**: Установлен на 5% от цены входа
